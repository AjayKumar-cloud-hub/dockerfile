# Hello World - Spring Boot + Java 25

Simple Spring Boot REST application using Java 25.

## Requirements

- JDK 25
- Maven 3.6.3+

## Run

```bash
mvn spring-boot:run
```

Or build and run:

```bash
mvn clean package
java -jar target/hello-world-0.0.1-SNAPSHOT.jar
```

## Test

Open:

http://localhost:8080/hello

Response:

Hello World
